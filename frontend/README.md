# Resume-JD Compatibility Analyzer - Frontend (React + Vite)

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Copy `.env.example` to `.env` (defaults are fine for local dev):
   ```
   cp .env.example .env
   ```

3. Make sure the backend is running at http://127.0.0.1:8000

4. Start the dev server:
   ```
   npm run dev
   ```

5. Open http://localhost:5173
